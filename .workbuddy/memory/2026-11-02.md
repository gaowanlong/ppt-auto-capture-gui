# 2026-11-02

## 项目：ppt-capture（ppt-auto-capture-gui）

- 克隆 `https://github.com/gaowanlong/ppt-auto-capture-gui`，v2.7.5 基线。Rust + eframe/egui 桌面工具：自动截取演示画面，停止后生成 PPTX。
- 结构要点：
  - `src/pptx/pptx_writer.rs` 从零构建 PPTX（ZIP + 手写 OOXML），`slide_xml.rs` 生成 slide XML。
  - `src/pptx/crop.rs`（2788 行）是裁剪算法核心：`detect_presentation_with_reference(&DynamicImage, Option<&FrameReference>) -> Option<(x,y,w,h)>`，`FrameReference::from_scaled_images` 用多帧对比识别静态任务栏/会议控件。均为 `pub(super)`。
  - `src/gui/export_panel.rs`「图片转 PPTX」页；`src/storage/import.rs` 图片目录 → PPTX。
  - 质量门禁：`cargo test --all-targets`、`scripts/check-clippy-baseline.sh`（基线 40，Linux CI 计数）、`scripts/check-rustfmt-changed.sh`、`tests/*.sh|rb` 契约测试。
  - 发版：推 `v*` tag 触发 `.github/workflows/build-release.yml`，产出 Windows exe / Linux tar.gz / macOS arm64 dmg。

### 本次新增（v2.8.0）
- 新增 `src/pptx/deck_crop.rs`：读取已有 PPTX（presentation.xml 顺序 → rels → p:pic 的 a:off/a:ext），复用裁剪检测，重写媒体部件并调整图片几何；其余部件逐字节复制，源文件只读。
- 判定规则：图片覆盖 ≥ 页面 35% 才当作截图；已有 `a:srcRect` 或带 rot/flip 的跳过；全出血图（≥85% 且居中）在「填满」模式下放大到整页；裁剪比例与框差异 ≤0.5% 直接吸附，避免发丝白边。
- 安全性：裁剪结果先落盘到 `<export>/.staging`，成功后才修改几何；失败/校验不过删除整个导出目录。
- UI：ExportPanel 增加「图片文件夹 / 已有 PPTX」模式切换、跨平台 .pptx 文件选择器、摆放方式（填满/保持原尺寸）、后台进度与中英结果文案。
- 测试：`deck_crop` 11 个单测（含经过 `import_directory` 的端到端回归），全套 282 个测试通过；clippy 35（≤40）。
